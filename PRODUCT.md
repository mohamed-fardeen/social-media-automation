# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js (App Router), Tailwind CSS, Framer Motion, Supabase, Python FastAPI (Backend).

## Users

Social Media Managers, Marketers, and Content Operators at Kelvin6k. They need to rapidly generate, review, and publish technical, high-quality B2B social content (LinkedIn, Instagram) about robotic 3D concrete printing.

## Product Purpose

The Kelvin6k Social Engine V2 is an AI command center that orchestrates fresh web research, RAG synthesis, strategy ideation, copywriting, visual direction, and image generation using supervised autonomous agents (Gemini 2.5 Flash/Pro, Llama 3). Success means the user can safely approve and publish high-quality, technically accurate 3DCP posts without writing them from scratch.

## Positioning

It uses a Multi-Agent Swarm with specialized nodes (Strategist, Copywriter, Visual Director, QA Checkers) grounded in real Kelvin6k machine data (ATON, ATOM, G.MINI) and brand profiles, unlike generic ChatGPT wrappers.

## Operating Context

Operators use a dual-screen or large desktop setup. They review "Pending Approval" drafts, inspect pipeline logs to verify agent logic, and read the research evidence before publishing to LinkedIn or Instagram.

## Capabilities and Constraints

- Fully automated multi-stage pipeline: Research -> Strategy -> Ideas -> Copy -> Vision -> QA.
- Strict visual constraints: No human figures, no generic sci-fi robots. Authentic 3D concrete printing layer striations only.
- Strict copy constraints: Technical, engineering-focused tone.
- Drafts can be Approved, Rejected, or sent back for Revision (Regenerate).

## Brand Commitments

- Company: Kelvin6k
- Voice: Technical, engineering-focused, innovative, confident, practical, and future-oriented.
- Products: ATON (Large format robot), ATOM (Compact polar robot), G.MINI (Lab printer).
- Aesthetic: Industrial, premium, technical. No "AI Slop".

## Evidence on Hand

- Real product names, competitor lists, and past project names (THE ARC, ZOHO Project).
- Supabase vector store containing scraped knowledge chunks.
- Brand profile containing reference image arrays.

## Product Principles

1. **Operator Trust over Full Autonomy:** The user must be able to inspect every agent's reasoning (QA status, degraded steps, sources) before approving.
2. **Authentic Reality over AI Hallucination:** Visuals and copy must reflect real-world robotic construction constraints, not sci-fi fantasy.
3. **Professional Precision:** The interface itself must feel like a high-end industrial engineering tool, not a generic SaaS dashboard.
